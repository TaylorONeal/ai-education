# LMS handoff patterns

Use these rules in every skill that touches an LMS.

1. Read first, write later.
2. Confirm the exact course, assignment, quiz, page, or gradebook column before writing.
3. Prefer hidden, unpublished, draft, or manual-post states while the agent works.
4. Preview student-facing content before publication.
5. For grades, write only reviewed values and stop before posting or releasing them.
6. Keep a local artifact of what changed and why.
