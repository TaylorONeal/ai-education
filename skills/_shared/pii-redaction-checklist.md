# PII redaction checklist

Before adding examples, docs, screenshots, or generated artifacts to this repo, check for:

- Real student, parent, instructor, TA, staff, or school names.
- Real usernames, emails, phone numbers, addresses, or chat handles.
- Real course IDs, section numbers, assignment IDs, quiz IDs, calendar links, file paths, or LMS URLs.
- Institution branding unless the file is explicitly about neutral placeholders.
- Roster data, grades, accommodations, conduct notes, or individual student work.

Use placeholders such as `[COURSE]`, `[ROSTER]`, `[RUBRIC]`, `[ASSIGNMENT_ID]`, `[COURSE_ID]`, `[STUDENT_A]`, and `[LMS_URL]`.
