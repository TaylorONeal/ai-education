# Output artifact patterns

Good skill output separates the draft from the decision.

## Review table

Use when the teacher must inspect many items.

Columns: `Item_ID`, `Source`, `Draft_Result`, `Evidence`, `Confidence`, `Flag`, `Human_Decision`, `Human_Note`.

## Review queue

Use when only some items need attention.

Sections: `Must review`, `Likely fine`, `Missing evidence`, `Policy decision needed`.

## Change log

Use when the agent edits course materials.

Columns: `File_or_Page`, `Change_Made`, `Reason`, `Needs_Human_Check`, `Published_Status`.
