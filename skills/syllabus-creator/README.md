# Syllabus Creator, in depth

This skill turns course context into a syllabus draft. It is intentionally cautious: it asks for missing dates and policy language instead of making them up, and it ends with a human verification checklist.

## Best workflow

1. Run prof-brain if the course already exists. The syllabus creator should read the brain first so it can reuse real assignments, readings, policies, and exam patterns.
2. Provide the official academic calendar or the exact term dates you want used.
3. Provide required institutional language. If you do not have it, leave placeholders and verify later.
4. Draft the syllabus.
5. Run the checklist before sharing anything with students.

## What it should not do

Do not let the skill invent official policy text, disability accommodation language, academic integrity rules, contact hours, or institutional deadlines. It can draft around placeholders, but a human verifies the official language.

## Handoff to schedule-generator

The weekly outline is usually not detailed enough to build a course from. After the syllabus draft is approved, send the outline, term dates, meeting pattern, readings, assignments, quizzes, and exams to schedule-generator. That skill produces the detailed spreadsheet-style table.

## The guardrail

A syllabus is official once students receive it. AI drafts it. The instructor verifies dates, policy language, grading math, and tone before it goes anywhere.
