# Checking claims, in depth

Use [SKILL.md](SKILL.md) to audit numbers, calculations, and sources. This skill verifies work; it does not detect which model wrote it.

## A useful audit row

Record claim ID, exact quotation, source location, metric definition, recomputation, status (verified, incorrect, unverifiable), and the instructor's review decision. Count claims checked as well as claims omitted. An unavailable source is not an invented source.

## Check the denominator

A claim that 120 of 100 unique eligible people converted is inconsistent if each person can count only once. A 120% increase is possible. So is 1.2 conversion events per session when repeated events count. Confirm definitions, time windows, and units before labeling a percentage impossible. Negative counts may be invalid; negative net changes can be valid.

## Avoid authorship guesses

Curly quotes, polished prose, HTML classes, lists, timing, and vocabulary shifts do not reliably establish AI authorship or intent. Do not assign a detector score or attribute a submission to ChatGPT, Claude, Gemini, or another tool from formatting. Ask about the reasoning behind a verified discrepancy, within the course's published policy.

## Safe reports

Escape submission text in HTML and CSV outputs, label status in words, and keep identifiers private. Review every consequential finding against its source before sharing feedback. For a classroom demonstration, use an invented submission and data rather than a student's record.

## The guardrail

The instructor reviews the evidence and any response under the applicable course policy. The tool never files a misconduct report, imposes a penalty, or messages a student. Read [the agent guide](../../guides/agents.md) for connected access.
